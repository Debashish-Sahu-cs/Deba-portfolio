# 🚀 React Portfolio Website – High UI Edition

A modern, high-performance portfolio website built with React, focused on advanced UI/UX principles, smooth animations, accessibility, and scalable architecture.

This project demonstrates frontend engineering excellence through a production-quality interface and a structured, modular system design.

---

## 📌 Project Objective

The objective of this project is to design and develop a visually striking portfolio website that showcases professional identity, technical skills, and projects using advanced UI/UX principles.

The focus areas include:

- Component-based architecture
- Smooth animations and transitions
- Strong visual branding
- Performance optimization
- Accessibility best practices
- Responsive design across all devices

---

## ✨ Key Features

- High-impact animated Hero section
- Modular and reusable React components
- Dynamic Skills and Projects sections
- Interactive project cards
- Route-based multi-page architecture
- Reveal animations and load transitions
- Dark / Light theme toggle
- Fully responsive layout
- Accessibility-focused implementation (ARIA labels, alt text)
- Performance optimization with React lazy loading and memoization
- Admin panel with CRUD functionality for managing portfolio content

## 🧱 Architecture Overview

The project follows a modular, scalable architecture:

App
├──public/
├   ├── images/
└──src/
    ├── components/
    └── admin/

### Architectural Principles

- Reusable UI components
- Separation of concerns
- Route-based section structure
- Lazy loading of large components
- Memoization to reduce unnecessary re-renders
- Clean state management practices

## 🚀 Deployment Status

The project is currently not publicly deployed.

Reason:
The backend architecture uses MySQL for structured data management, and production-grade MySQL hosting was intentionally avoided to maintain architectural integrity rather than switching to limited free-tier database solutions.

The application can be deployed using:
- Vercel / Netlify (Frontend)
- Node hosting platforms (Backend)
- Managed MySQL server

Deployment can be configured when production-level database hosting is available.

## 📦 Installation & Setup

### 1️⃣ Clone Repository

git clone "https://github.com/Debashish-Sahu-cs/Deba-portfolio"
cd <project-folder>

### 2️⃣ Install Frontend Dependencies

npm install

### 4️⃣ Start Frontend

npm start

### 5️⃣ Setup Backend

npm install
npm run dev

For backend code GitHub repo:- "https://github.com/Debashish-Sahu-cs/Deva-portfolio-backend"

Configure database credentials in backend `.env`.
